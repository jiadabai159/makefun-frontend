# make.fun frontend

A fast, easy-to-use frontend for make.fun, built from static files on make.fun's public API.

Entry for the make.fun bounty [makefun-frontend-01](https://make.fun/bounty/makefun-frontend-01): "Build the best make.fun frontend".

- Live bounty board with each bounty's reward / live pot, entry fee and time left
- Bounty pages with rules, rewards and dates
- Leaderboards
- Public account profiles

Every surface is reachable by a link and by its own URL. Read-only: no sign-in, no writes, data from `https://make.fun/api` only.
